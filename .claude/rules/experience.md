# 사용자 경험 규칙

- 첫 화면은 **모바일 세로**가 기준이다. 데스크톱은 그 다음.
- 스와이프 25장을 **90초 안에** 끝낼 수 있어야 한다. 화면당 인터랙션 1개.
- 추천 카드에 매치율만 있고 **근거 사진과 이유가 없으면 미완성**이다.
- 외부 이미지는 우리 서버에 복제하지 않는다. `next/image`의 원격 로더 + 출처 표기.
- 로딩 스피너보다 스켈레톤. 취향 분석 대기 중에도 사용자가 뭘 기다리는지 알게 한다.
- 새 상태관리 라이브러리를 추가하지 않는다. URL과 서버 상태로 안 되는 게 생기면 그때 논의.
